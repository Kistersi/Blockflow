# BLOCKFLOW

A block-placement puzzle game for iPhone, prepared as a Progressive Web App (PWA).

Features include Classic and Challenge modes, a 10×10 board, 90° rotation (no mirroring), achievements, local progress storage, and offline support after the first successful online load.

The game files are being added to this repository. GitHub Pages can serve the app from the `main` branch root once the PWA files are present.
